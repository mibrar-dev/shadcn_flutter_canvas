## 5. Defects filed (emitter fn + fixture + message — lib/ NOT touched)

* **DEFECT-1 (gate-4/5 blocker, G-track owns). Missing clash
  disambiguation on the §8.4 page path.** `emitPage`/`buildPageFile`
  (`canvas_core/lib/src/emit/project_writer.dart`) emit a bare
  `import 'package:flutter/material.dart';` plus collector lines, and
  the `ImportCollector` (`emit_context.dart`) models imports as bare
  strings with no `hide`/prefix combinator. Every G3 emitter's
  `collectImports` (`g3_emitters.dart`, via
  `kG3KitImport = 'package:flutter_shadcn_kit/flutter_shadcn_kit.dart'`)
  adds the kit GLOBAL barrel — which re-exports `flex.dart`
  (`Column`, `Expanded`, …) and `shared/theme/theme.dart` (`Theme`) —
  and `emitPrimitivePageFiles` (`expr_emitter.dart:875-877`) adds ALL
  extra-emitter imports unconditionally, even on pages using zero kit
  widgets (primitives page). Fixtures: all three emitted pages.
  Analyzer message: `ambiguous_import` (×11) + knock-on
  `invocation_of_non_function` (×8), e.g. `'Chip' ... defined in ...
  material/chip.dart and .../display/chip/chip.dart`. Fix direction
  (not applied): port the legacy `_screenFile` H2 convention
  (`codegen_bundle.dart`: `_screenFlutterHideWidgets`,
  `_screenFlutterHideMaterial`, `_screenMenuHide`, `tabs as tabs`,
  per-kind narrow barrels via `_barrelFile`) into the AST path —
  narrow per-kind kit imports + computed `hide` lists + a combinator
  model on the collector. Note the legacy tables do NOT yet cover the
  global-barrel-only clashes (`Column`/`Expanded`/`Theme` have no hide
  rows — legacy screens never import the global barrel), so this is a
  real port + extension, not a copy.
* **DEFECT-2 (gate-4 infos, G-track owns). Non-const emission.**
  `formatExpression`/adapters (`expr_emitter.dart`) emit non-const
  `Column(`/`Chip(`/`TextArea(` call sites → 12 ×
  `prefer_const_constructors` across the three pages; `buildAppTheme`
  (`project_writer.dart`) emits `final scheme = const ...` → 1 ×
  `prefer_const_declarations` (`app_theme.dart:6`). Fixtures: all pages
  + theme shell. (G2's trailing-comma policy keeps multi-arg widgets
  full-split; const-ness must be layered on, not stripped.)
* **DEFECT-3 (gate-3 direction, G-track owns). `lib/main.dart` not
  format-clean.** `buildMainDart` (`project_writer.dart`) output is the
  single `Changed` file under `dart format --set-exit-if-changed`
  (missing blank line between the theme and router imports). All six
  other lib files are format-clean.
* **DEFECT-4 (writer completeness, G-track triage). No platform
  scaffolding.** `scaffoldProject` emits no `web/` (nor mobile) folders,
  so `flutter build web` on raw writer output fails before compiling
  with "not configured for the web". Either emit a minimal `web/`
  scaffold or document `flutter create . --platforms web` as the
  runbook step (this run used the latter, in `/tmp` only).
* **Known v1 limitations observed (NOT defects — G2/H docs already own
  them, recorded so the evidence reads correctly):** `scaffold`,
  `avatar`, `text`, `badge`, `card` have no AST emitters → honest
  `Text('<kind> (not yet bridged)')` placeholders, 8 sites, all in the
  primitives page (compile-clean; gate 7 fails, gates 4–5 unaffected);
  the `isRow` structural row (`n_heroRow`, gap 8.0) emits as `Column`
  (isRow transparency is documented G2 v1 behavior); column gap
  separators (`SizedBox(height: 12)`) appear around the explicit
  `SizedBox(height: 24)`; single-screen `buildMainDart(hasRouter:
  false)` emits `MaterialApp(theme:)` with NO `home:` (moot here —
  3 screens → router path — but open for single-screen exports).
* **Driver artifact (NOT a generator defect):**
  `non_constant_identifier_names` on `bio_bioController` comes from
  this driver's `bio_` id-prefix colliding with fixture id `bio`
  (`planModelFields` allocates `<id>Controller` verbatim); the raw
  fixture id `bio` yields clean `bioController`.
