# Shadcn Canvas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone Flutter-web canvas where users drag real shadcn components onto phone screens, theme them, preview taps, and export a prompt, a single `screen.dart`, or a clean-folders bundle installable via `shadcn screen add`.

**Architecture:** `canvas_app/` Flutter web app (copied from `shadcn_flutter_kit/docs/` deploy pattern) renders real registry widgets from a generated catalog; a pure-Dart `ScreenDoc` model (manual JSON, zero Flutter imports in `lib/canvas/` except the catalog) flows into three exporters; the CLI reuses the exporters plus the existing installer graph for `screen add`.

**Tech Stack:** Flutter 3.44 / Dart 3.12, `go_router`, `shared_preferences` (web localStorage), `json_schema` (CLI validation, already a dep), `dart test` + `flutter test`, GitHub Pages via `bluefireteam/flutter-gh-pages@v9`.

**Spec:** `docs/superpowers/specs/2026-09-04-shadcn-canvas-design.md`. Phase order is load-bearing: P0 → P1 → P2a → P2b → P2c → P3 → P4 → P5. Do not start a phase until the previous one's success criteria pass.

**Global constraints (apply to every task):**
- `canvas_app/lib/canvas/*.dart` (except `component_catalog.dart`) must NOT import `package:flutter/*` — they compile for CLI reuse. Carve-out (verified in Stream B): `canvas_store.dart` defines its own minimal `ChangeNotifier` (same `addListener`/`removeListener`/`notifyListeners`/`dispose` API, documented NOTE comment) instead of importing Flutter's — a `Listenable` adapter may live under `lib/ui/` later. Verify with `grep -r "package:flutter" canvas_app/lib/canvas/screen_doc.dart canvas_app/lib/canvas/canvas_store.dart canvas_app/lib/canvas/prompt_builder.dart canvas_app/lib/canvas/codegen_single.dart canvas_app/lib/canvas/codegen_bundle.dart canvas_app/lib/canvas/share_codec.dart` expecting no output.
- Editor chrome (`lib/ui/palette_panel.dart`, `inspector_panel.dart`, `theme_bar.dart`, toolbar) uses ONLY registry widgets via `lib/shadcn_ui.dart` (dogfooding rule, spec §4). Gate: `grep -rn "Material(\|Cupertino" canvas_app/lib/ui/palette_panel.dart canvas_app/lib/ui/inspector_panel.dart canvas_app/lib/ui/theme_bar.dart` expecting no output. Exempt: `main.dart` shell, `preview_player.dart` + `phone_frame.dart` content areas (user content).
- Every new hand-written Dart file < 300 LOC (generated `_impl/embedded_sources.dart` exempt); helpers go in `_impl/`-style sibling files.
- `flutter analyze` must pass after every task.

```json
      "type": "object",
      "required": ["w", "h"],
```

- [ ] **Step 1: Write the validator** (`tool/validate_canvas.dart`)

```dart
import 'dart:convert';
import 'dart:io';

const _allowedTypes = {'string', 'bool', 'double', 'enum', 'color', 'icon', 'slot'};
const _allowedGroups = {'content', 'style', 'state', 'layout', 'behavior', 'advanced'};

/// Testable core: returns per-manifest counts plus `componentId/canvas/prop` errors.
({int checked, int withCanvas, List<String> errors}) validateManifest(
  Map<String, dynamic> manifest,
) {
  final components = manifest['components'] as List;
  var checked = 0, withCanvas = 0;
  final errors = <String>[];
  for (final c in components) {
    checked++;
    final id = (c as Map)['id'] as String;
    final canvas = c['canvas'];
    if (canvas == null) continue;
    withCanvas++;
    final props = (canvas as Map)['propsSchema'] as List?;
    if (props == null || props.isEmpty) {
      errors.add('$id/canvas: propsSchema must be a non-empty array');
      continue;
    }
    for (final p in props) {
      final prop = p as Map;
      if (!_allowedTypes.contains(prop['type'])) {
        errors.add("$id/canvas/${prop['name']}: unknown type ${prop['type']}");
      }
      if (!_allowedGroups.contains(prop['group'])) {
        errors.add("$id/canvas/${prop['name']}: unknown group ${prop['group']}");
      }
      final enumValues = prop['enum'] as List?;
      if (prop['type'] == 'enum' && (enumValues == null || enumValues.isEmpty)) {
        errors.add("$id/canvas/${prop['name']}: enum type needs non-empty enum list");
      }
      _checkDefault(prop['type'] as String, prop['default'], enumValues,
          "$id/canvas/${prop['name']}", errors);
    }
  }
  return (checked: checked, withCanvas: withCanvas, errors: errors);
}

void _checkDefault(
  String type,
  Object? def,
  List? enumValues,
  String ctx,
  List<String> errors,
) {
  switch (type) {
    case 'string':
      if (def is! String) errors.add('$ctx: default must be a string');
    case 'bool':
      if (def is! bool) errors.add('$ctx: default must be a bool');
    case 'double':
      // JSON has no int/double split: accept num, normalize with (v as num).toDouble().
      if (def is! num) errors.add('$ctx: default must be a number');
    case 'color':
    case 'icon':
      if (def is! String) errors.add('$ctx: $type default must be a string');
    case 'enum':
      if (enumValues == null || !enumValues.contains(def)) {
        errors.add('$ctx: default must be one of $enumValues');
      }
    case 'slot':
      break; // slots carry widget trees, not scalar defaults
  }
}

int main(List<String> args) {
  final manifestPath = args.contains('--manifest')
      ? args[args.indexOf('--manifest') + 1]
      : 'shadcn_flutter_kit/flutter_shadcn_kit/lib/registry/manifests/components.json';
  final manifest = jsonDecode(File(manifestPath).readAsStringSync()) as Map<String, dynamic>;
  final result = validateManifest(manifest);
  if (result.errors.isNotEmpty) {
    for (final e in result.errors) stderr.writeln('ERROR $e');
    // `dart file.dart` ignores int-returned exit codes on some SDKs — set explicitly.
    exitCode = 2;
    return 2;
  }
  stdout.writeln('✓ ${result.checked} checked, ${result.withCanvas} canvas-ready');
  return 0;
}
```

```dart
import 'package:test/test.dart';
import '../../tool/validate_canvas.dart';

Map<String, dynamic> _manifestWith(Object? canvas) => {
      'components': [
        {'id': 'button', 'canvas': canvas},
        {'id': 'card'},
      ],
    };

Map<String, dynamic> _prop(String type, Object? def, {List<String>? enumValues}) => {
      'name': 'p', 'type': type, 'default': def, 'group': 'style',
      if (enumValues != null) 'enum': enumValues,
    };

void main() {
  test('accepts valid canvas and counts correctly', () {
    final r = validateManifest(_manifestWith({
      'propsSchema': [_prop('enum', 'primary', enumValues: ['primary', 'secondary'])],
    }));
    expect(r.errors, isEmpty);
    expect(r.checked, 2);
    expect(r.withCanvas, 1);
  });

  test('rejects unknown type, unknown group, empty enum', () {
    final r = validateManifest(_manifestWith({
      'propsSchema': [
        _prop('bogus', 'x'),
        {'name': 'q', 'type': 'string', 'default': 's', 'group': 'nope'},
        // empty enum list fires BOTH the empty-list and the default-not-in-enum errors
        _prop('enum', 'a', enumValues: []),
      ],
    }));
    expect(r.errors, hasLength(4));
  });

  test('rejects default outside enum and mistyped defaults', () {
    final r = validateManifest(_manifestWith({
      'propsSchema': [
        _prop('enum', 'ghost', enumValues: ['primary']),
        _prop('bool', 'yes'),
        _prop('double', 'wide'),
      ],
    }));
    expect(r.errors, hasLength(3));
  });
}
```

### Task 8b: build-time source embedder (unblocks offline web codegen)

Web builds cannot read registry files from disk at runtime, so Task 11's single-file exporter would only emit `// needs:` comments. Fix: embed the sources at build time.

**Files:**
- Create: `canvas_app/tool/embed_sources.dart` (pure Dart, run with `dart run`)
- Create (generated, never hand-edit): `canvas_app/lib/canvas/_impl/embedded_sources.dart`

- [ ] **Step 1: Write the embedder**

```dart
// Reads components.json canvas blocks for canvas-ready kinds, resolves each
// kind's files[] + shared[] closure (reuse the file/destination lists verbatim),
// and emits a const map: destination -> file content.
import 'dart:convert';
import 'dart:io';

void main() {
  final root = File(Platform.script.toFilePath()).parent.parent.parent;
  final manifest = jsonDecode(File(
    '${root.parent.path}/shadcn_flutter_kit/flutter_shadcn_kit/lib/registry/manifests/components.json',
  ).readAsStringSync()) as Map<String, dynamic>;
  final kitRoot = '${root.parent.path}/shadcn_flutter_kit/flutter_shadcn_kit/lib/registry';
  final out = StringBuffer()
    ..writeln('// GENERATED by tool/embed_sources.dart — DO NOT EDIT.')
    ..writeln('const Map<String, String> kEmbeddedSources = {');
  for (final c in manifest['components'] as List) {
    if ((c as Map)['canvas'] == null) continue;
    for (final f in (c['files'] as List)) {
      final src = (f as Map)['source'] as String;
      final content = File('$kitRoot/$src').readAsStringSync();
      out.writeln("  ${jsonEncode(f['destination'])}: ${jsonEncode(content)},");
    }
  }
  out.writeln('};');
  File('${root.path}/lib/canvas/_impl/embedded_sources.dart')
    ..parent.createSync(recursive: true)
    ..writeAsStringSync(out.toString());
  stdout.writeln('embedded ${out.length} chars');
}
```
